# Pictures & Assets Directory

This folder contains all the photos and imagery used across the Megan Foster Supply Chain Portfolio website (Transpoco design theme).

## 🖼️ How to Swap Photos

All images currently point to modern SVG placeholders in this directory. You can easily swap them with your own `.jpg`, `.png`, or `.webp` photos anytime:

### 1. Megan's Profile / Headshot
* **Current File**: `pictures/profile-placeholder.svg` (referenced in `index.html`)
* **Recommended format**: Square or portrait (`4:3` or `1:1` ratio, min 600x600px)
* **To swap**:
  * Option A: Drop your headshot here as `pictures/profile.jpg` (or `.png`) and update line with `<img src="pictures/profile-placeholder.svg" ...>` in `index.html` to `pictures/profile.jpg`.
  * Option B: Save your headshot directly over `pictures/profile-placeholder.svg`.
